## Использование
- [masks.py](#2 функции для маскировки номер счета и карты)  
в модуле 2 функции для подмены реальных цифр номера счета и номера карты на *
- [processing.py](#2 функции возвращают операции по дате и по статусу)  
в модуле функция, которая возвращает выбранные по значению состояния операции и отсортированные по дате операции
- [widget.py](#работа со счетами и картами и датами)  
функция из модуля возвращает номер счета или номер карты, другая функция возвращает дату в формате дд.мм.гггг
